# Why "triaina"?

**triaina** (Greek *τρίαινα*, roughly "TREE-eh-nah") means **trident**: the
three-pronged spear that Poseidon, Greek god of the sea, never leaves home without.
*Tri* is "three", as in tripod and triangle.

## The printer has a borrowed name

The printer this project runs on is the ELEGOO **Neptune** 4.

Neptune is Poseidon after a move to Rome. When the Romans took in the Greek
gods, they kept nearly everything: the sea, the storms, the horses, the beard,
the bad temper and the trident. What they changed was the name tag. Zeus became
Jupiter, Ares became Mars, and Poseidon started answering to Neptune.

To be fair to Rome: it already had a Neptunus, a modest god of fresh water. He
was handed Poseidon's entire portfolio, sea, ships, earthquakes and trident, in
what may be the biggest promotion in mythology.

So the Neptune 4 is named after the Roman edition of a Greek original. This
project hands it back the original Greek spear, Greek label included.

| | Greek original | Roman edition |
|---|---|---|
| God of the sea | Poseidon | Neptune |
| His spear | *triaina* | *tridens* (hence "trident") |
| In this project | the software | the printer |

## Three prongs

A trident has three points, and so does this one:

1. **Print**: the Neptune 4 as a normal FDM printer.
2. **Cut**: the same machine with a drag knife, cutting vinyl stickers.
3. **The Pi**: the Raspberry Pi that prepares the jobs and decides which of the
   first two is on duty today.

Also, a trident is a sharp point on the end of a stick. So is a drag knife.
Poseidon would approve, and probably ask for a sticker.

## How to write it

Lowercase in code, commands and package names: `triaina`, `python -m triaina`.
It is one word, not "Tri-Aina", and it has nothing to do with trains.
